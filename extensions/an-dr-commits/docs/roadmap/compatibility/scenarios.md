# Acceptance scenarios

These black-box scenarios define the transition contract. They are intentionally independent of either extension's source layout.

1. Open a repository and inspect graph history, refs, uncommitted changes, commit details, and file diffs.
2. Discover workspace, nested, external, and linked-worktree repositories; select, star, persist, and restore one.
3. Exercise branch, tag, commit, working-tree, remote, credential, and interactive-editor flows in disposable repositories, including failure and cancellation.
4. Apply graph filters, display settings, navigation, load-more, refresh, and column persistence.
5. Open revisions and comparisons with the final `an-dr-commits` virtual-document scheme.
6. Use the Activity Bar sidebar, inline blame, Code Review hand-off, SCM actions, and terminal integration when their counterpart capabilities exist.
7. Migrate a copied VS Code profile, uninstall, reinstall, and verify the extension removes only state that it owns.
8. Install the final identity in a clean profile on Windows, Linux, and macOS.
